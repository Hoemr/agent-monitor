# Agent Monitor v0.8.0

## New features

- Expressive pixel pets: Nailoong, Doraemon, Ti Hun and the British blue cat.
  Pets follow live task status, celebrate new completions, react to questions
  and failures, and rest when idle. Settings includes artwork previews and
  immediate pet switching.
- A Rust pet engine with state-image packs, Shimeji-ee pack import, native
  interaction menus, and roaming sprite physics.
- Antigravity desktop and CLI monitoring, with independent conversations and
  read-only SQLite access including committed WAL updates.
- Pinned conversations that stay at the top across restarts, custom session
  names, and the latest recorded model shown for each conversation.
- Multiple Codex account homes and clearer desktop, VSCode and Terminal labels.

## Improvements

- Unread completion markers persist until the individual conversation is read;
  opening the panel does not clear them. Mark one or all completions as read.
- More reliable running, waiting, cancelled and completed status across Codex,
  Claude Code, DSH and ZCode, including DSH model recovery from compressed logs.
- VSCode session links with focused-chat verification and accurate fallback
  reporting when only the workspace can be selected.
- More consistent pet moods, edge hiding, resizing, outside-click dismissal
  and settings persistence.

## Packaging and updates

- macOS arm64; minimum macOS 14.5.
- Persistent macOS signing identities preserve permission continuity between
  builds signed with the same identity. Moving from an old ad-hoc signature
  requires a new permission grant.
- Locally signed builds retain their original signing identity and are rebuilt
  locally. Public release packaging requires a persistent distribution identity,
  separately from the Tauri updater signing key.

See [UPDATING.md](../UPDATING.md) for signing setup and
[ASSETS.md](../ASSETS.md) for artwork provenance.
