# Agent Monitor v0.8.1 — Windows support

## Windows downloads

- **Agent-Monitor-windows-x64-setup.exe**: recommended installer for Windows
  10/11 x64. Installs for the current user and sets up WebView2 if needed.
- **Agent-Monitor-windows-x64.zip**: extract and run `agent-monitor.exe`.
  Requires an existing Microsoft Edge WebView2 Runtime. Prefer the installer
  for system notification support.
- **SHA256SUMS-windows.txt**: checksums for both Windows downloads.

Native Windows terminal and VSCode sessions are read from the current user's
Codex, Claude Code, DSH, ZCode and Antigravity data directories. Settings live in
`%LOCALAPPDATA%\agent-monitor`. WSL profiles are not discovered automatically.

The Windows build includes the same pet artwork, animations, tray controls,
edge hiding, pinned/custom-named sessions and unread completion indicators.
Windows uses native process detection and notification APIs; Settings no longer
asks for macOS permissions. Ctrl+, opens Settings.

## Windows limits

- Task clicks focus a running application at L1. Conversation/tab selection is
  not verified; select the intended conversation yourself. Application focus
  never marks a Windows conversation read. Individual and bulk read actions
  remain available in the task panel.
- With multiple terminal windows, select the intended window/tab manually.
  Windows may prevent focusing an elevated application.
- Downloads are unsigned with Authenticode, so Windows may show an
  unknown-publisher/SmartScreen prompt. Updates use manual downloads.
- Automated Windows checks do not replace hands-on checks of mixed-DPI monitors,
  desktop dragging, notifications and real agent application switching.

See the [Windows guide](../WINDOWS.md) for paths and installation details.

## macOS

The macOS arm64 download retains the existing persistent local signing identity.
It is not Apple-notarized and continues to use manual installation, as in v0.8.0.
