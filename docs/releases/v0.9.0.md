# Agent Monitor v0.9.0

## 灵动岛与面板

- macOS 新增轻薄玻璃材质的灵动岛，可在设置的「桌宠」页或托盘菜单中开启。
- 收起态展示正在工作的 agent 和待处理状态，悬停展开，移开收起，点任务行跳转。
- 展开面板每项采用两行布局，展示标题、时间、agent、宿主、模型、跳转等级和状态。摘要可在悬停说明中查看。
- 全部会话均可通过滚动访问，顺序、状态色、语言和相关显示设置与桌宠共享。
- 桌宠面板同步采用圆润卡片和柔和材质。两种面板共享新完成标记和已读状态。
- 修复构建缓存遗漏灵动岛与共享前端资源的问题。

## ZCode

- macOS 根据会话 ID 读取当前标题，通过原生任务搜索选择目标，并核对实际会话标题后确认 L3 跳转。
- 重名、无标题、无法确认目标和重叠切换请求均给出明确结果，灵动岛可直接显示跳转提示。
- 状态读取结合转录中的回合结束证据，支持标准 JSON 转义。
- 会话定位需要辅助功能权限及索引中的唯一非空标题。

## Downloads

- `Agent-Monitor-macos-arm64.zip` for Apple silicon Macs running macOS 14.5 or later.
- `Agent-Monitor-windows-x64-setup.exe` for Windows 10/11 x64. The installer can set up WebView2.
- `Agent-Monitor-windows-x64.zip` for portable use with an existing WebView2 Runtime.
- `SHA256SUMS-macos.txt` and `SHA256SUMS-windows.txt` contain the download checksums.

## Installation and platform support

macOS uses the same persistent local signing identity as v0.8.1 and manual installation.
Quit Agent Monitor, extract the ZIP and replace the installed App. This build is
locally signed and has not been Apple-notarized. macOS may require approval to open it.

Windows uses manual installation. The downloads are unsigned with Authenticode
and may show a SmartScreen prompt. Windows task clicks provide application-level
focus at L1. Dynamic Island and verified ZCode session selection are macOS features.

The release packages include the current pet artwork, tray controls, session
pinning and naming, unread completion indicators and shared panel styling.
